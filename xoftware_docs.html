Introduction

Xoftware Pay is a high-performance payment gateway infrastructure designed for reliable transaction processing. This documentation provides technical specifications for integrating our Merchant API, supporting QRIS, E-Wallet, and Virtual Account payment channels.

Integration Libraries

To accelerate your integration process, we provide ready-to-use SDKs and boilerplate scripts for various languages:

  • Official SDK Repository: https://github.com/xoftware-id/pg-lib
  • Examples: Contains Node.js, PHP, Python, and Go implementation examples.
Integration Architecture

The system operates as a stateless middleware between your application backend and upstream payment providers. Integration is achieved via RESTful API calls and asynchronous Webhook notifications.

Standard Response Envelope

All API responses follow a consistent JSON structure:

FieldTypeDescription
codeIntegerHTTP Status Code.
errorBooleanTrue if the request failed.
messageStringDescriptive status or error message.
dataObjectThe actual payload (varies by endpoint).
Standard Workflow
  1. Merchant Authentication: Acquire API_KEY and WEBHOOK_SECRET via the Merchant Dashboard.
  2. Endpoint Configuration: Define a persistent Webhook URL to receive asynchronous payment state updates.
  3. Transaction Initiation: Execute a POST request to the Transaction endpoint with the required payload and HMAC signature.
  4. State Management: Implement an idempotent handler for incoming Webhook payloads to finalize transaction states in your local database.
  5. Security Validation: Enforce IP Whitelisting for all outbound API requests.
